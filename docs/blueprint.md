# **App Name**: Karbi zomato

## Core Features:

- Restaurant Discovery: Browse a list of available restaurants with essential information like cuisine, ratings, and estimated delivery time.
- Menu Browsing: View detailed menus for each restaurant, including dish names, descriptions, prices, and images.
- Shopping Cart & Order Placement: Add desired food items to a shopping cart, review the order summary, and securely place an order.
- User Authentication: Allow users to create accounts, log in, and manage their profile and order history.
- Order Status Tracking: Provide real-time (simplified) updates on the status of an active order (e.g., preparing, out for delivery, delivered).
- Restaurant & Dish Search: Enable users to search for specific restaurants or dishes using keywords and apply filters like cuisine type or rating.
- AI-powered Meal Suggestions: Offer personalized meal recommendations as a tool based on the user's past order history and popular local dishes.

## Style Guidelines:

- Primary color: A rich, appetizing red (#CF2617) inspired by a ripe tomato, signifying fresh food and energetic service.
- Background color: A subtle, desaturated off-white with a hint of red (#F5F0F0) to ensure high readability and a clean, fresh feel for the user interface.
- Accent color: A vibrant berry pink (#E085B3) to provide a dynamic contrast for interactive elements, highlights, and calls to action.
- Body and headline font: 'PT Sans' (sans-serif) for its modern yet friendly feel, ensuring excellent legibility for menus and application content.
- Utilize simple, outline-style icons for navigation and functional elements to maintain a clean and uncluttered interface.
- Implement a clear card-based layout for restaurant listings and menu items, making content easily digestible on mobile and desktop.
- Incorporate subtle hover and tap animations on interactive elements like buttons and menu items for a responsive and engaging user experience.
